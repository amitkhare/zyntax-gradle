Android-host source ports for native-platform and Gradle file-events.

Base repositories:
https://github.com/gradle/native-platform
https://github.com/gradle/gradle-fileevents
Exact selected source commits, component profile and patch hashes are recorded
in SOURCE-PROVENANCE.properties beside this notice. A build profile is not a
claim that the corresponding full Gradle distribution has been qualified.

Changes: scope sysctl to Apple where upstream has not already done so, and
GNU strerror_r to glibc; build the
native-platform Java companion for Android aarch64; map the shared Android
platform identity to Android-named native resources in file-events.
For milestone 26's integrated file-events, replace the desktop-only GNU libc
probe with explicit Android target selection and Bionic compilation enforcement;
keep the original inotify implementation and watcher lifecycle unchanged. Generate
authentic matching Java/native version values. Cross-compile native sources
with Android NDK r29 for arm64-v8a/API 24 and static libc++.
Build the original curses component against the checksum-pinned official
Android ncurses package, with one Android resource identity. The ncurses
package and terminfo database remain explicit terminal-runtime dependencies;
they are not redistributed in this bundle.

This is a standalone component/probe bundle, not a Gradle distribution.
Original component licenses and official NDK notices are included in licenses/.
The standalone file-events probe also includes SLF4J and its MIT license;
the integrated file-events API uses Java's built-in logging.
