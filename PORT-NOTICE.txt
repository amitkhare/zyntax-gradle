Android-host source ports for native-platform 0.22-milestone-28 and
Gradle file-events 0.2.7.

Base sources:
https://github.com/gradle/native-platform/commit/87f4647e90db6006bf357db0ba7fa29925dcc32e
https://github.com/gradle/gradle-fileevents/commit/08be35d81f4d6336ce4666122c0c72a97b11a7e9

Changes: scope sysctl to Apple and GNU strerror_r to glibc; build the
native-platform Java companion for Android aarch64; map the shared Android
platform identity to Android-named native resources in file-events. Generate
authentic matching Java/native version values. Cross-compile native sources
with Android NDK r29 for arm64-v8a/API 24 and static libc++.

This is a standalone component/probe bundle, not a Gradle distribution.
Original component licenses, SLF4J's MIT license, and official NDK notices
are included in licenses/.
